Tools (5)

One shared board, changed one object at a time.

add_node

Create a positioned card and automatically start a canvas when no canvas ID is supplied.

get_canvas

Read the current revision, cards, coordinates, and connections.

update_node

Patch card content, color, category, or position without replacing omitted values.

connect_nodes

Add an optionally labeled, directed link between two existing cards.

export_canvas

Download editable JSON or a standalone SVG that preserves the spatial layout.
